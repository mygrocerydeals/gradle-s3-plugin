# Security Policy

## Supported versions

Only the latest release of the plugin receives security fixes. See the [Gradle Plugin Portal page](https://plugins.gradle.org/plugin/com.mgd.core.gradle.s3) for the current version.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions or pull requests.

Report them privately through GitHub: open the repository's **Security** tab and select **Report a vulnerability**. Include the plugin version, a description of the issue and steps to reproduce it. A maintainer will acknowledge the report and keep you updated while a fix is prepared.
